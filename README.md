# Daily English Lab — 학습 콘텐츠

[daily-english-lab](https://github.com/sylvanus4/daily-english-lab) 앱이 매일 받아가는 콘텐츠입니다.

- `manifest/latest.json` — 발행된 날짜 목록. 앱은 이것만 보고 무엇을 받을지 정합니다.
- `days/YYYY-MM-DD.json` — 그날의 상황 대화 (상황 4~5개 × 턴 4~5개)
- `images/day-NNN/sN.webp` — 상황 이미지 (실사, 1200px, q80)
- 오디오는 Google Drive 링크로 각 day json 안에 있습니다.

`{name}` 은 학습자 이름 플레이스홀더이며 앱이 표시 시점에 치환합니다.

콘텐츠는 자동 생성물이며, 품질 게이트를 통과한 것만 커밋됩니다.
